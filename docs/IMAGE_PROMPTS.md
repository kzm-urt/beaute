# Image Generation Prompts

## Home Category Tiles

Use these prompts to replace the temporary category photography with generated brand-owned assets. Recommended size: `1536x1024` or `2048x1152`, landscape, no text, no logos, no watermarks.

Shared direction:

```text
Use case: product-mockup
Asset type: website category tile background
Style/medium: luxury Japanese beauty editorial photography
Composition/framing: horizontal still life with generous negative space, premium magazine crop, subject slightly off-center
Lighting/mood: soft cinematic studio light, warm highlights, quiet luxury, refined and tactile
Color palette: ivory, deep espresso, muted gold, category accent color used subtly
Constraints: no text, no logo, no watermark, no visible brand names, no hands, no faces, no clutter
Avoid: stock-photo smile, harsh neon, plastic-looking packaging, apparel/fashion-item hero shots, busy backgrounds
```
